# 资产规格说明

## 1. 人物与奇波正比资产卡（Standard Asset Cards）
- **画风**：纯 2D 日系动画赛璐璐平涂风格（纤细均匀深暖褐/暗棕紫线稿、干净平涂色块与轻盈克制的单层硬边阴影）。
- **四格规格**：
  - 总卡尺寸：`2700 × 3242` PNG（底色 `#F7F8FA`）。
  - `01_face.png`：`1024 × 1536`（2:3 竖幅面部/主体特写）。
  - `02_front.png` / `03_left.png` / `04_back.png`：`1254 × 1254`（1:1 方形全身三视图：0° 正面、90° 左侧面、180° 纯背面，头顶至鞋底/赤足底水平对齐）。
  - 棚拍底色：统一淡冷灰蓝（`#D8E3F4 ~ #E2EAF4`），空手自然站姿，无地面投影，不对称部件三视角严格左右镜像。

## 2. 人物 Q 版三视图（Chibi 3-View Turnarounds）
- **比例与画风**：约 2.3–2.5 头身精致日系 Q 版，完整保留每位角色的发色渐变、头饰、耳/角/翼/尾、服饰纹样与左右不对称细节。
- **单张规格**：`1672 × 941`（16:9 横幅）PNG、纯白底（`#FFFFFF`）、无文字无投影，左/中/右等距排布 **正面 / 90° 左侧面 / 180° 纯背面**。
