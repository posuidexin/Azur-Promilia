# 角色资产卡制作规格说明

## 1. 正比角色资产卡（Standard Character Asset Cards）
- **画风定位**：纯正 2D 日系动画赛璐璐平涂风格（纤细均匀深暖褐/暗棕紫 2D 线稿 + 干净纯净平涂色块 + 克制单层硬边赛璐璐浅阴影，零 3D 体积厚涂与柔焦雾感）。
- **四格无损拼合规范**：
  - 总卡尺寸：`2700 × 3354` PNG（底色 `#F7F8FA`），四格原图未缩放、未裁切、未调色。
  - `01_face.png`：`1024 × 1536`（2:3 竖幅头肩面部特写）。
  - `02_front.png` / `03_left.png` / `04_back.png`：`1254 × 1254`（1:1 方形全身三视图，上下留白 7%–8%，三视角头顶至鞋底/赤足底水平对齐）。
  - 棚拍底色：统一淡冷灰蓝（`#D8E3F4 ~ #E2EAF4`），空手标准自然站姿，零地面投影。
  - 严格校验不对称部位三视角左右镜像（`02` 画面左 = 角色右；`03` 前景 = 角色左；`04` 画面左 = 角色左，且背面严格手背朝后、双腿垂直对称）。

## 2. Q 版三视图资产卡（Chibi 3-View Turnaround Sheets）
- **画风与比例**：约 2.3–2.5 头身精致日系 Q 版（圆润脸颊、明亮大眼、精致 2D 动漫线稿与光泽发色），100% 还原正比设定中的发色渐变、兽耳/精灵耳/龙角/羽翼/尾巴、服饰纹样与左右不对称细节。
- **单张版式**：原生 `1672 × 941`（16:9 横幅）无损 PNG、纯白底（`#FFFFFF`）、零文字零投影，左/中/右等距排布 **0° 正面 / 90° 左侧面 / 180° 纯背面** 并保持水平等高对齐。

## 3. 视频与分镜比例参考
- **露米（Lumi）× 女性星临者**：详见 `references/露米与女性星临者比例参照图.png`——实机像素实测露米身高约为女性主角的 **15%–16%（约 `1 : 6.5`）**，全身高度约等于主角 **1 颗头的高度**；使用同规格 `1254×1254` 单格叠层时将露米缩至女性星临者的 **16.2%** 即可对齐。
